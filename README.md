# Moon Calculator

A beautiful moon phase simulator that shows the moon view from different locations on Earth with interactive 3D visualization.

## 🌙 Live Demo

View the Moon Calculator here: **[https://roxign.github.io/MoonCalculator/moon-view.html](https://roxign.github.io/MoonCalculator/moon-view.html)**

## Features

- Real-time moon phase visualization
- Multiple viewing locations across the globe
- Interactive 3D Earth view
- Detailed moon information and statistics
- Responsive design for all devices

## How to Use

1. Open the link above in your web browser
2. Select locations A and B to compare moon views from different places
3. Adjust the date and time to see how the moon changes
4. Use the interactive controls to explore different perspectives

Enjoy observing the moon! 🌕
